### Image-based seeds

Also called image-based markers, this information is a set of pixels per training image containing pixel coordinates and their ground-truth information, called a label (an integer number related to the class that the pixel belongs to).

The files on this folder are merely examples created using [CreateSeedsFromAllPix](https://github.com/IsabelaBB/GFLIM_BoFP/blob/main/CreateSeedsFromAllPix.py). Since in Helminth eggs there are only one class per image, and this class is indicated in the image filename, the image-based seeds can be extracted using this tool.

Imge-based seeds files can also be created from manually-drawn markers using [iDISF](https://github.com/IsabelaBB/iDISF).
